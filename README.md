# PLP Python Week 4 Assignment

- `welcome.py` - one `welcome()` function that prints a welcome message, called three times instead of repeating the code.
- `toolbox.py` - three small functions: `double`, `is_pass`, and `greet` (with an optional greeting).

## Reflection

The `greet` function was the hardest to write because I had to use a default parameter value (`greeting="Hello"`) and build the message with an f-string, so the comma and exclamation mark had to be in exactly the right places.
